The shared Core pin admits tested Node24.18+ wrappers while retaining the secure
Node22.22.2+ floor. Edge has a portable JavaScript/WASM module builder for the
YouTube catalog and TV receiver, matching npm tarball source collection, a safe
checksum-gated archive installer, strict installed-Core identity and native Node
version checks, and stopped runit service installation. Existing configuration
and provider credentials are preserved; newly added provider entries stay disabled.

preservation and core mismatch. Core's 14 wrapper tests passed under a fresh
Node24.18.0 npm install with no native payloads. The Full dev.46 images remain
frozen at Node22.22.2. At this implementation checkpoint, no Edge Node module
archive or Android/Bionic runtime result is claimed. Spotify/AirPlay native closure,
remaining media/receiver coverage and product physical gates stay open.
