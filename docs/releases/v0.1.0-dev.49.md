# Edge checkpoint v0.1.0-dev.49

Public prerelease [dev.47](https://github.com/ZombieBox-tv/zombiebox-gateway-edge/releases/tag/v0.1.0-dev.47)
contains Android/Bionic API24 Core for ARM64 and ARMv7 plus matching portable
YouTube catalog and TV receiver modules. Public prerelease
[dev.48](https://github.com/ZombieBox-tv/zombiebox-gateway-edge/releases/tag/v0.1.0-dev.48)
contains both ABI-specific AirPlay/UxPlay modules with source archives. The
module installer requires dev.47's exact Core commit, installs native Termux
packages, checks required RTP elements and validates both executables before
switching a stopped service. Existing credentials/PIN remain private and intact.

Host evidence: 31 Edge tests, formatting/dependency/shell checks, Core
ARM64/ARMv7 ELF/API24/archive audits, both Node module manifests, AirPlay
ARM64/ARMv7 PIE/direct-import audits, source archive identities and SHA256
sidecars. All 14 dev.47 and eight dev.48 GitHub asset digests matched the locally
built files. Anonymous AirPlay download was checked separately. No Android
execution, receiver A/V, mDNS, accounts, OEM or thermal result is inferred.

The optional Spotify binary remains unpublished. Its current go-librespot
revision links `xlab/vorbis-go`, which has no explicit license in the pinned
module archive or upstream repository. The Full Spotify image already published
under dev.46 needs the same dependency review. A build or source archive alone
does not settle redistributability. Product milestones M10/M11 remain open.
