# Edge v0.1.0-dev.46 — public Core and Node module delivery

The public [dev.45 prerelease](https://github.com/ZombieBox-tv/zombiebox-gateway-edge/releases/tag/v0.1.0-dev.45)
contains 14 assets: two Android/Bionic API24 Core binary/source pairs and their
checksums, plus two portable JS worker binary/source pairs and checksums. Exact
Core source is `0bd2142d676cdbf30407db68eb0c0800bde2dc4b`; the Edge build
recipe is `7ed2b85297f8777d06babb933685287eda8dfd29`. No old tag or asset
was changed.

ARM64 Core: `7a3c371b3084302170ab4595fb32f51bfc0bd5d3ef4758502e91f5e94d7c438c`.
ARMv7 Core: `19c72e0996aca4d13934127ad50543905241df81532c74b14ae52008cbefe1e9`.
The NDK audit found only libc/libdl/liblog imports, all resolvable at API24, with
16 KiB ARM64 and 4 KiB ARMv7 load alignment. The release verifier checked archive
extraction, file hashes and corresponding-source hash on both ABIs.

The YouTube catalog and TV receiver archives contain 11 and 110 exact npm
packages, respectively. Their matching source archives include all 121 verified
npm tarballs, first-party worker sources/build recipe, license supplements and a
per-package notice inventory. A source-free host simulation installed both
workers stopped, preserved provider credentials and rejected mismatched Core IDs.
GitHub's remote digest/size matched every local asset, and both module archives
were downloaded anonymously and revalidated.

The native Node runtime comes from Termux `nodejs-lts` and is version-checked at
installation. It is not embedded in the module archives. No Android execution,
real TV Code/DIAL session, account authorization, audio/video reception or thermal
result is claimed. Spotify/AirPlay prebuilt modules and product physical gates
remain open.
