# Edge checkpoint v0.1.0-dev.51

The [dev.50 prerelease](https://github.com/ZombieBox-tv/zombiebox-gateway-edge/releases/tag/v0.1.0-dev.50)
has 30 published assets: eight coherent binary packages, their exact matching
source archives and fourteen named SHA256 sidecars. All packages identify Core
`69048d043ab023ad9bc15836e87311ebbc04cc3c` and Edge
`1badd426606ab82cc9aa679d739ead8b1ca43ddf`. Remote sizes and SHA256
digests match every local asset; an anonymous Spotify ARMv7 download matched too.

Host archive extraction and installer manifest validation passed for Core ARM64/
ARMv7, YouTube and TV receiver, AirPlay ARM64/ARMv7 and Spotify ARM64/ARMv7.
Spotify's linked module graph excludes the former unlicensed Vorbis binding and
includes exact MIT `oggvorbis`/`vorbis` modules. Its direct and transitive Termux
native library imports satisfy the API24 audit. The installer pins native package
versions, checks both executables before stopping a service and preserves account
configuration. `make format format-check deps-check check` passes 32 tests.

This is a public development release, not evidence of actual Android execution,
Spotify account/audio, AirPlay A/V, TV Code/DIAL, mDNS, latency or thermal
acceptance. Product milestones and physical gates remain open.
