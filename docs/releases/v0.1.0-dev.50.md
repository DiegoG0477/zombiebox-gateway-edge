# Edge checkpoint v0.1.0-dev.50

The development dependency pins Core dev.47. Spotify source preparation replaces
the unlicensed Vorbis binding with pinned MIT modules. ARM64 and ARMv7 Android/
Bionic API24 candidates compile with exact SHA-locked Termux FLAC/MPG123/Ogg build
packages. Host ELF/import/alignment checks validate direct and transitive native
library closure; all linked Go modules have notice/source receipts. The optional
installer validates the reviewed decoder identity and matching Core, installs
fixed native package versions, smoke-checks both executables, preserves private
configuration and creates a stopped service. Edge format/dependency and 32 tests
pass.

The candidates carry `candidateOnly=true` and are not public binary releases.
Core, Node and AirPlay binaries must be rebuilt against the same exact Core commit
before Spotify can join a single installable Edge release. Android execution,
Spotify account/audio and thermal acceptance remain open. No product milestone
closes.
